# 让国内和微信稳定打开：域名 + 备案 + 境内托管

目标：拿到一个 `https://你的域名` 的地址，国内能稳定打开，微信里能直接访问。

**总成本约 ¥150–350 / 年，总周期 3–4 周（其中备案审核占 7–20 个工作日）。**

备案本身不收钱。你付的是「域名年费」和「一台境内服务器」，后者是备案的前提条件。

---

## 一、先想清楚：为什么必须这台服务器

ICP 备案是**按域名 + 接入服务商**办的，不是按网站办的。要备案，必须有一个境内接入资源（云服务器或轻量应用服务器）来提供"备案服务号"。

所以顺序是：**买域名 → 买服务器 → 备案 → 才能让域名指向境内并对外访问**。

没有"只买域名、不买服务器就能备案"的路径。那台服务器同时也能直接用来托管静态站，钱不算白花。

---

## 二、买域名（1 天）

**在哪里买**：腾讯云、阿里云、华为云的域名注册。

**必须注意**：

- **必须在境内注册商买**。境外注册的域名无法做工信部备案，这是最常见的白跑一趟。
- **做完实名认证**。用个体户营业执照或经营者身份证都行，但**备案主体要和域名持有人一致**，否则会被驳回。
- 类型建议 `.cn`（约 ¥25–40/年）或 `.com`（约 ¥60–90/年）。
- 名字短、好读、和"AI 成本/指数"相关即可，别用生僻词。

> 域名有效期至少买 2 年，备案审核时剩余有效期太短可能被要求续费。

---

## 三、买一台最低配服务器（当天）

**用途**：拿备案服务号 + 顺便托管静态站。

- 腾讯云「轻量应用服务器」，1 核 2G，新用户促销常在 ¥100–300/年
- 阿里云类似产品，价格相近
- 系统选 Ubuntu 22.04 或 Debian 12，别选 Windows（贵且没必要）

**地域**：选你目标读者近的，一般选华东/华北/华南。备案地不影响使用。

**两件事要确认**：

1. 服务器带**公网 IP**
2. 买够能开**备案服务号**（下单后在控制台「备案」里能看到）

---

## 四、提交 ICP 备案（当天提交，等 7–20 个工作日）

在云厂商的备案系统里在线提交（免费）。

**准备材料**：

- 个体户营业执照（彩色扫描/拍照）
- 经营者身份证正反面
- 域名证书（注册商可下载）
- 手机号、邮箱（会电话核验，务必保持畅通）
- **网站名称**：中文，不能含"中国/中华/国家/政府/国际"等词，不能纯英文，不能太泛（"AI 指数"这类通常可以，具体看当地管局）

**流程**：

```
提交 → 云厂商初审（1–3 工作日）→ 提交管局 → 管局审核（7–20 工作日）
```

期间可能接到核验电话，问"网站是做什么的""是不是你自己做的"，如实回答即可。

**注意**：备案审核期间，域名**不能**指向境内服务器对外提供访问。可以先在服务器上把站点跑通，但别解析域名。

## 五、部署静态站（备案下来后 1 小时）

假设用那台服务器。三种做法，推荐第一种：

### 做法 A：Nginx 直接托管（最简单）

```bash
# 服务器上
sudo apt update && sudo apt install -y nginx
sudo mkdir -p /var/www/teci
# 把 publish/index.html 和 og.png 传上去
sudo rsync -av ./publish/ /var/www/teci/
```

`/etc/nginx/sites-available/teci`：

```nginx
server {
    listen 80;
    server_name 你的域名;

    root /var/www/teci;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 页面每天更新，别让浏览器缓存太久
    location = /index.html {
        add_header Cache-Control "public, max-age=600";
    }
    location = /og.png {
        add_header Cache-Control "public, max-age=86400";
    }
}
```

启用后 `sudo nginx -t && sudo systemctl reload nginx`。

### 做法 B：对象存储（COS/OSS）+ 自定义域名

更便宜（存储费几乎为 0），但要绑定已备案域名，配置比 A 多一步。适合以后流量变大时再迁。

### 做法 C：继续用 GitHub Pages，域名 CNAME 过去

**不行**。备案要求域名指向境内接入商，CNAME 到 github.io 不满足备案的接入要求，会被注销备案。

### HTTPS（免费）

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名
```

Let's Encrypt 免费，90 天自动续期。微信和浏览器都要求 HTTPS，这步别省。

## 六、接上每日自动更新（30 分钟）

两种方式，推荐第一种（少一层依赖）：

### 方式 1：直接在服务器上跑（推荐）

服务器上装 Python，用 cron 每天执行：

```bash
# 服务器上
sudo apt install -y python3 python3-pip git
git clone <你的仓库> /opt/teci
cd /opt/teci && python3 scripts/build_teci.py

# crontab -e 加一行：每天 09:10 构建并同步
10 9 * * * cd /opt/teci && python3 scripts/fetch_models.py; python3 scripts/build_teci.py && rsync -a publish/ /var/www/teci/
```

优点：不依赖 GitHub、不需要配密钥、抓取失败也不影响线上（`build_teci.py` 会用旧快照）。

### 方式 2：GitHub Actions 构建后 rsync 到服务器

适合你已经在用 GitHub 仓库管理代码。需要在仓库 Secrets 里存服务器 SSH 私钥，在 workflow 末尾加一步 rsync。

**安全提示**：给这个部署用的 SSH 密钥单独生成一对，权限只限 `/var/www/teci`，别用 root。

## 七、上线检查清单

- [ ] 域名已实名、在有效期内
- [ ] 备案号已拿到
- [ ] 页脚显示备案号，且链接到 `beian.miit.gov.cn`（**管局会抽查，不展示会被要求整改**）
- [ ] HTTPS 正常，`http` 自动跳 `https`
- [ ] 手机上打开：图表能横向滑动，字号可读
- [ ] 微信里打开：先发给自己试，确认能进
- [ ] 英文版 `?lang=en` 正常
- [ ] 分享卡片有标题和缩略图（改 `build_teci.py` 里的 `SITE_URL`）

页脚已经预留了备案号位置：在 `site/index.html` 搜 `id="beian"`，把 `hidden` 去掉并填入真实编号，重新跑 `run.cmd` 即可。

## 八、常见坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 域名在境外注册商买 | 无法备案，白买 | 只在腾讯云/阿里云/华为云买 |
| 域名持有人 ≠ 备案主体 | 驳回 | 都用个体户执照 |
| 备案期间域名已解析到境内 | 可能被驳回 | 审核期先不解析 |
| 网站名称含敏感词 | 驳回 | 用中性描述，如「AI 成本观察」 |
| 忘了页脚备案号 | 抽查不合格，限期整改 | 上线即加 |
| 只买域名不买服务器 | 无法备案 | 服务器是备案前提 |
| 备案下来就换服务器 | 需办「接入变更」 | 换之前先在新服务商办接入 |

---

## 九、和省钱有关的实话

- **备案免费**，别为"代办备案"付钱。自己提交就能过，材料齐的话不难。
- **服务器促销价通常只限新用户首年**，续费会涨。第二年可以对比几家再迁（迁服务器要办接入变更，别忘了）。
- **不需要买"企业建站套餐"**。你这个站是一个 HTML 文件，Nginx 托管就够。

## 十、时间线

| 时间 | 做什么 |
|---|---|
| 第 1 天 | 买域名、买服务器、提交备案 |
| 第 2–4 天 | 云厂商初审（期间把静态站在服务器上跑通，但别解析域名）|
| 第 5–25 天 | 管局审核（等；可以继续用 GitHub Pages 对外）|
| 备案通过当天 | 解析域名、配 HTTPS、上线 |
| 之后 30 分钟 | 接上 cron 每日更新 |
