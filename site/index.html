为什么需要这个指数

市面上已有的算力指数量的都是 $/GPU-小时，那是供给侧的机器租金。 但企业买 AI 不是在租机器，是在买 token。同一张卡，换个模型或换个推理框架， 交付同样工作量所需的成本能差好几倍。所以需要一把针对 token 的尺子。

L1 · 挂牌价指数

混合价 = (4 × 输入价 + 1 × 输出价) / 5  （USD / 百万 token）

4:1 是典型对话负载的输入输出 token 结构。这个权重是口径的一部分，改它必须升版本号。 指数取档位内中位数而非均值，避免个别极端定价或促销价把整体带偏。

注意：未被第三方评分的模型仍计入 L1，而它们占了样本的大多数。 所以 L1 中位数很大程度上反映的是"尚未评级那批模型"的价格水平，不是一个"好用模型"的价格。 要判断性价比请看 L2。

L2 · 单位智能成本

每智能点成本 = 混合价 ÷ 第三方智能分

这是"买到一分智能要花多少钱"。它解决了 L1 的一个致命缺陷：贵模型通常更强， 单看价格会误判性价比。

已知局限：把能力分当作可除的基数，隐含"能力可线性度量"的假设； 而智能分本质上是序数指标，不是基数。因此 L2 只在同档位内比较有效， 不做跨档位的绝对解读。这一条我们不会为了图表好看而略过。

样本规则

  • 只纳入最近 12 个月上市、且未标注下线日期的模型。理由：本指数回答的是"现在买哪家最实惠"， 混入 2023 年的退役型号会让"最便宜"变成一个没人用的选项，也会破坏不同时期的可比性
  • 剔除 :free 促销免费档与 :batch 批量档——它们不是同一件商品
  • 剔除价格缺失或为 0 的条目
  • 档位划分：智能分 ≥55 旗舰，≥40 中端，<40 轻量
  • 无第三方评分的模型计入 L1，不计入 L2

尚未启用的层级

L3 · 有效成本指数：用标准化负载实测吞吐、首字延迟与重试率， 折算成"交付 100 万有效输出 token 的真实全成本"。这是本指数最终要去的方向， 但需要持续付费跑基准测试，当前版本未启用。在它上线之前， 本页所有数字都不代表真实可用成本，只是挂牌价口径。

修订与连续性

口径一经发布不追溯修改。要改口径就发新版本指数，旧序列冻结。 每次运行都会在 data/teci_history.csv 追加一行，时间序列由此长出来。

数据来源

价格与能力分：OpenRouter 公开模型目录， 其中智能分由 Artificial Analysis 提供。本页不自行抓取厂商定价页， 也不对厂商口径做二次解释。

数据源边界：该目录只收录在 OpenRouter 上架的模型。豆包（Doubao，火山引擎直供）等未上架该平台的模型不在样本内，因此本指数不覆盖它们。字节跳动的 Seed 系列在目录内，但尚未取得第三方智能评分，只参与价格统计，不进入性价比排名。

这个指数能拿来做什么
  • 采购比价：判断某家报价是否偏离市场，而不是只看绝对价格
  • 降本复盘：同一任务换模型后，单位智能成本是升还是降
  • 国产替代测算：把"便宜但略弱"和"贵但更强"放在同一坐标里看
  • 趋势观察：等历史序列攒够，可看"智能的通胀/通缩"

不适合用来做什么：不构成投资建议， 不能作为衍生品或合约的结算基准。若真有机构想拿它做基准，需要走正式的指数授权与审计流程， 届时口径与治理必须重新设计——这一步远比做一个网页难。
